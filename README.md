# Projet Web Dynamique - Site sur le Népal

## 📋 Description du projet
Site web dynamique sur le Népal réalisé dans le cadre du module "Techniques Web & Multimédia".
Le projet comporte une partie statique (site vitrine) et une partie dynamique (application avec base de données).

## 🎯 Objectifs pédagogiques
- Maîtriser les technologies web : HTML5, CSS3, JavaScript
- Implémenter un site web responsive et moderne
- Développer une application PHP avec base de données MySQL
- Gérer l'authentification et les CRUD (Create, Read, Update, Delete)
- Intégrer des éléments multimédias (vidéos, galeries, cartes)
